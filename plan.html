Every surface opens telling you what needs attention. The hub agent parses all threads and raises elements you answer in place. The log stream stays — demoted. Companion of PLAN.md.

The stance ① Web · attention console ② Web · session detail ③ Web · agent surface ④ CLI · hub (board) ⑤ CLI · hub watch ⑥ CLI · answering ⑦ omp plugin views

orientation line   "⚠ tilt needs approval · deploy canary 2/3 · docs idle 12m"
⚠ NEEDS YOU        approval requests + questions → inline answer box, type + ⏎
⏳ RUNNING          one digest line per active session
💤 IDLE            sessions waiting for work → "assign:" input right there
      … raw log stream one keypress / one click away (kept, no longer the headline)

Three verbs per item: answer (type → delivered via hub_send_message, item resolves), dismiss, open. You open the hub and are told what needs you.
